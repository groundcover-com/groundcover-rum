### Fixed
- **Browser — errors Safari hides as "Script error." are reported.** Safari and every browser on iOS hide an error thrown in a `setTimeout`, `setInterval`, `requestAnimationFrame` or event-listener callback, or passed to `reportError()`, when the script is served from another origin, even with `crossorigin` and CORS headers, so those errors never reached groundcover. The SDK now runs those callbacks inside a try/catch and notes values passed to `reportError`, and reports such errors with their real type, message and stack. The error is rethrown unchanged, an error is never sent twice, and errors from third-party scripts loaded without `crossorigin`, which every browser hides, stay unreported. Callbacks registered before `init` aren't covered, and React 19's errors are covered when `init` runs before `react-dom` is imported.
