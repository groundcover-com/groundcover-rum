### Added
- **Browser — `options.errors.wrapCallbacks` reports errors Safari hides as "Script error.".** Safari and every browser on iOS hide an error thrown in a `setTimeout`, `setInterval`, `requestAnimationFrame` or event-listener callback when the callback's script is served from another origin, even with `crossorigin` and CORS headers, so those errors never reached groundcover. With `wrapCallbacks: true` the SDK runs those callbacks inside a try/catch and reports such errors with their real type, message and stack. The error is rethrown unchanged, an error is never sent twice, and browsers that already show these errors in full report them as before. Off by default.
